# PROJETO DE ARRAY

Esse projeto simples é só uma forma de brincar com array, eventos e formes.

| :rocket: URL         | https://array-eight.vercel.app/

## Como executar

Abra `index.html` em um navegador. Não há dependências ou etapa de build.

## O que o exercício demonstra

- Mostrar o array inicial `[1, 2, 3, 4, 5]`.
- Acrescentar o número 6 com `push` a cada clique.
- Inverter o array atual com `reverse`; um segundo clique restaura a ordem.
- Montar outra lista com os valores do formulário, sem aceitar campos vazios.

Os valores do formulário são exibidos como texto, nunca interpretados como HTML. As listas ficam apenas na memória e reiniciam ao recarregar a página.

## Verificação manual

Teste cliques repetidos, inversão duas vezes, entrada vazia, texto com `<` e navegação por teclado. Confira a página em uma tela estreita.
